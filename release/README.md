# Release tooling

Status: v1alpha
Content: informative

`release/` is reserved for deterministic public bundle manifests and release tooling activated by issue #17 after issue #10 creates a real contract bundle.

Do not place credentials, signing keys, private producer coordinates, private source, operator configuration, or empty placeholder artifacts here. Release jobs remain disabled until the bundle, manifest, checksum, SBOM, attestation, and separate consumer-verification contract are implemented and reviewed.

See `docs/release-integrity.md`.
