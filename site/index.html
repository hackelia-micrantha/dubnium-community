Reproducible engineering environments with explicit runtime control

Dubnium combines declarative NixOS environments, operator tooling, runtime resource modes, writable user configuration, observability, and governed AI/automation into one inspectable engineering platform.

Components

Dubnium is composed from bounded pieces with explicit ownership. Status labels describe current maturity; the Technical Overview explains their state models and intentional boundaries in more detail.

Active

Declarative platform

NixOS and Home Manager define rebuildable operating-system, user-environment, security, and resource-policy inputs.

Evidence: architecture and reproducibility documentation.

Active / evolving

dubctl

Host/operator entry point for inspection, bounded selections, development workflows, and explicit declarative apply.

Evidence: implemented operator surface.

Active

modectl

Guarded runtime posture transitions between interactive desktop, media-priority, and compute work.

Evidence: desired/observed reconciliation model.

Active

configctl

Writable user-configuration ownership, first-run contracts, and drift/reconciliation beside declarative configuration.

Evidence: managed/local/custom/adopted layer model.

Experimental

System themes

Reproducibility

Declared platform, user, and project environments make endpoints easier to rebuild, replace, review, and audit.

Observability

Desired state, observed runtime state, durable domain state, and bounded evidence remain distinct and inspectable.

Governed capabilities

Identity and connectivity inform policy, while privileged effects still require explicit bounded authority.

AI and automation

Models can propose intent while deterministic validation, policy, lifecycle state, and effect execution remain explicit.

Project status

Incubating. Core platform tooling and several interoperability boundaries are implemented and exercised. Contracts, conformance, technical documentation, and adopter integration are active work; APIs and deployment forms remain experimental until their contracts and operational evidence stabilize.
